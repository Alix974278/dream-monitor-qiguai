# 到梦空间定时抢课助手

**提前选好想抢的课程或校园活动，设置「定时报名」，报名一开放，脚本就会用你的账号自动提交报名。** 程序在 Windows 本机运行，设好任务后可以关闭看板网页，保持主程序运行、电脑开机联网即可。

**[下载 v2.5.1 Windows 完整包](https://github.com/Alix974278/dream-monitor-qiguai/releases/download/v2.5.1/dream-monitor-v2.5.1-windows-x64.zip)** · [在线浏览源码](dream-monitor/) · [版本下载与更新记录](https://github.com/Alix974278/dream-monitor-qiguai/releases)

## 怎么定时抢课

1. **选课。** 登录后打开「我能报名」，最近要开抢的活动排在前面。卡片上的「报名开始」就是开抢时间，按北京时间显示。
2. **设定时。** 点开尚未开放、已公布报名开始时间的活动，点击「定时报名」并确认。已经开放报名的活动可以直接点「立即报名」。
3. **查结果。** 到点后，本机后台自动发起报名。打开「定时报名」查看任务状态，到「我的活动」核对报名记录。

## 挑课时可以看什么

- **资格和名额。** 「我能报名」会筛出当前账号已确认符合条件的活动，同时排除已报名、满员或已截止的场次。卡片显示剩余名额和开抢倒计时，平台暂未返回资格的活动可在「资格待确认」中查看。
- **列表更新。** 浏览时，后台发现变化会提示「有新数据」。点击后再更新列表，并尽量保留正在看的位置。

## 在 Windows 上使用

1. 下载上方的 **Windows 完整包** 并解压。包内已包含运行环境。
2. 双击 `dream-monitor/01-启动原版优化助手.cmd`，在打开的本地看板登录自己的账号。
3. 升级已有版本时，先关闭旧程序，把新版程序文件覆盖到原目录，保留自己的 `data` 文件夹和 `config.yaml`。
