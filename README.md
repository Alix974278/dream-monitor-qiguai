# 到梦空间活动看板 · 奇怪同学维护版

基于 LinXiaoAn（林小安）开源的 dream-monitor，由奇怪同学维护，沿用 Opus 修复版并使用 ChatGPT 和 Codex 辅助改版。[完整来源与贡献](CREDITS.md) · [上游许可证](LICENSE)

**[下载 v2.5.1 Windows 完整包](https://github.com/Alix974278/dream-monitor-qiguai/releases/download/v2.5.1/dream-monitor-v2.5.1-windows-x64.zip)** · [下载项目源码](dream-monitor-v2.5.1-source.zip)

解压完整包，双击 `01-启动原版优化助手.cmd`，在本机浏览器打开看板。升级时先退出旧程序，再将程序文件覆盖到原目录，并保留自己的 `data` 和 `config.yaml`。

- “我能报名”包含已确认符合条件、尚未开放报名的活动，最近开抢的活动优先展示。资格不明确时可切换到“资格待确认”。
- 后台发现新数据时显示提醒。点击更新后尽量保留正在阅读的活动位置。
- 定时报名由本机后台执行。任务等待期间需要保持电脑开机、联网、主程序运行。

本版本已做离线回归和桌面、移动宽度的界面验证。真实报名结果以平台反馈为准。
