# 本地用户管理（新增）

## 适用情况

你删除了一个浏览器配置文件（或清了 Cookie）后，CMD 启动时仍显示原来的用户数。
原因：浏览器只保存前端 Cookie，后台账号另存在 `data/users.db`。
现在可以在网页里直接认人、删除，无需手工编辑 SQLite 或猜测用户 ID。

## 安装升级（先退出程序）

1. 关闭正在运行的 `01-启动原版优化助手.cmd` 窗口。
2. **务必先复制一份整个 `data` 文件夹和 `config.yaml` 到安全位置**，这是升级前额外备份。
3. 将新版压缩包完整解压到原 `dream-monitor` 文件夹，遇到“覆盖同名文件”选择覆盖。
4. **保留旧 `data` 文件夹、`config.yaml`、`secret.key` 和 `identity.json`**。新版包不包含旧账号数据，不需要你重新登录其他账号。
5. 双击 `01-启动原版优化助手.cmd`，网页登录、活动获取、筛选和抢课继续沿用原版。

## 打开管理页面

方法一：普通活动看板左下角头像 → `用户管理（本机管理员）`。
方法二：运行 `03-打开用户管理.cmd`。
方法三：在运行这套程序的 Windows 电脑上访问 `http://127.0.0.1:8770/admin.html`。

此页面**不需要管理员口令**。在运行助手的 Windows 电脑上打开管理页面，即可自动读取本机账号。列表与删除接口仅限 127.0.0.1/localhost 本机访问，局域网设备不能远程删用户；跨网站删除被来源校验和自动 CSRF 校验拦截。**注意：同一台电脑上能访问本地管理页的人都可以查看脱敏用户列表和执行已确认的删除。**

## 删除你不再使用的那个账号

1. 列表会显示**姓名、学校、部分遮挡的登录账号或手机号、用户 ID、任务数量和网页会话数**。
2. 先核对姓名、手机号末四位和用户 ID，确认是要清除的那个人。
3. 点击该账号右侧的“删除账号”。当前浏览器正在登录的账号显示为“当前登录账号”，没有删除按钮。
4. 弹窗会再次显示姓名、脱敏手机号和用户 ID。确认是目标账号后，直接点击**“确认删除”**。不需要输入 ID，也没有勾选框。
5. 成功后网页用户数会即时减少，CMD 也会打印新的总数。CMD **启动时的旧日志不会自动改写**。

操作只清理本机助手中的这名用户，不会注销官方到梦空间账号；其他用户的任务和活动缓存不受影响。

## 注意事项（非常重要）

- **正在等待、准备或执行报名的账号无法直接删除**，程序会拒绝。先在该账号取消定时任务，确认后台任务退出后重试；这样避免删人瞬间还在发报名请求。
- 不能删除当前浏览器正在登录的账号。要删它，先在活动看板退出登录，或换一个浏览器/浏览器配置文件打开用户管理。
- **删除就是彻底删除，不留备份、无法恢复**：该账号的资料、保存的密码与 Token、网页会话、全部定时任务和 `data/users/` 下的缓存文件一并清除，数据库也会清理残留。此人之后重新登录会重新注册，可以正常使用定时报名。
- 如果某个缓存文件正被 Windows 占用，账号仍会删除，那个文件会在下次删除或下次启动时自动清掉。
- 旧版本（v2.2 及以前）删除时生成过 `data/admin_backups/` 文件夹，里面有删除当时所有账号的资料。不需要的话，关闭程序后把这个文件夹整个删掉即可，不影响运行。
- 若 Windows 正在占用该账号的文件、数据库写入发生冲突或其他保护条件不满足，删除会被拒绝或回滚。不要强制删除 `users.db`、`secret.key`、`identity.json`。
- 不要把含 `data` 的程序目录分享给其他同学。让其他人使用时，发**未登录的原始安装包**即可。

## 运行和验证说明

- 本地管理员页面 `/admin.html`、脱敏用户列表、删除保护、彻底删除（无备份）、只删目标 UID 对应文件和主库记录。
- 原来 `dmclient.py`、`monitor.py`、`rules.py`、`ui/app.js`、`ui/login.js` 等登录、活动筛选及抢课核心文件未改动。
- Linux 容器内 118 项离线自动检查通过，另有本地 HTTP 接口安全检查、模拟数据的 Chromium 页面交互检查；**未在真实 Windows 机器或真实账号数据库上执行删除测试**。
- 使用本次升级前，请把今晚已经成功的原版文件和 `data` 备份好，以便出现兼容问题时回退。
